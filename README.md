### 📌 Function

**What I Learned**

함수를 정의하고 매개변수를 전달하며 결과값을 반환하는 기본 구조를 학습했습니다.

**Practice**

함수를 직접 작성하면서 필요한 인자가 전달되지 않았을 때 발생하는 오류 등을 확인하고

**Key Point**

> 오류 메시지를 단순히 실패로 생각하지 않고, 코드에서 무엇이 잘못되었는지 찾기 위한 정보로 활용하고 있습니다.

### 📌 Pandas & DataFrame

**What I Learned**

**Key Point**

> 데이터를 코드로 불러오고 구조를 확인한 뒤 필요한 값을 추출하는 기본적인 데이터 처리 흐름을 익히고 있습니다.
